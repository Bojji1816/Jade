# 時尚翡翠珠寶品牌 Codex Project

最後更新：2026-07-14
狀態：Active project

## Project Purpose

這個 project 用來管理一個現代簡約翡翠首飾品牌的 6 個月創業進度。

核心方向：

- 現代簡約翡翠首飾。
- 女性自用為主，同時包含女朋友買給男朋友/伴侶的送禮場景。
- 男裝烏雞款放在同一品牌內測試，不另開品牌。
- 價格帶：HK$500-1500。
- 香港起步，全球網店同步準備。
- 第一批 10 件四會明料是學習批。
- 第二轉入貨安排在第 2 個月。

## How To Use This Project

1. Start each week from `knowledge-base/02-weekly-task-tracker.md`.
2. Use `templates/material-inventory-template.md` to record each jadeite material.
3. Use `templates/product-sku-template.md` when a material becomes a product idea.
4. Use `templates/weekly-dashboard-template.md` after products go live.
5. Record major business decisions in `knowledge-base/03-decisions-log.md`.
6. Add competitor notes to `knowledge-base/05-competitor-research.md`.
7. Manage reusable brand copy in `copywriting/`.
