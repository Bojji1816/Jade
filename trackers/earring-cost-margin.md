# 耳環成本及毛利粗算

最後更新：2026-08-25
狀態：Draft v0.4

用途：按目前耳環貨 M007-M011 粗算完整成本、可接受售價和毛利。這份表用來判斷哪些耳環值得鑲嵌、哪些要調整設計或售價。

## 計算假設

- 匯率：1 CNY ≈ HK$1.16。
- 鑲嵌成本 base case：350 CNY / 對耳環。即「三百幾」的中位估算。
- 鍍金：如未包含在 350 CNY 內，另加 30 CNY / 對。
- 包裝成本：HK$30 / 件。
- M008-M012 為 5 件總價 945 CNY，暫用平均成本 189 CNY / 件計。
- M009 已於天光墟權記鑲嵌成耳環，實際加工成本 42.2 CNY；手工一般但很平，可作低加工方案參考。
- M010 已於晶韵珠寶鑲嵌成耳環，實際加工成本 150 CNY。
- M011 已於福小琪鑲嵌成耳環，實際加工成本 137 CNY；材質已確認為 925 銀電鍍黑。
- 以下未計：平台手續費、運費補貼、壞件損耗、重拍/返工成本、證書成本。

公式：

```text
總成本 HKD = (明料成本 CNY + 鑲嵌成本 CNY + 鍍金成本 CNY) x 1.16 + 包裝成本 HKD
毛利 HKD = 售價 HKD - 總成本 HKD
毛利率 = 毛利 HKD / 售價 HKD
```

## 初步結論

1. 鑲嵌耳環不應再放在 HK$580-780 入門價。
   - 如果完整鑲嵌成本約 300-380 CNY / 對，HK$780 以下大多只是薄利或虧本。

2. M008 原本 HK$580-780 價帶需要重設。
   - 若做完整 S925 huggie，合理售價應靠近 HK$1080-1280。
   - 若想保留入門價，只適合用現成銀圈/簡單配件，不做完整鑲嵌。

3. M009/M010 是比較值得鑲嵌的耳環候選。
   - M009 已用權記 42.2 CNY 低加工方案完成，成本遠低於 base case，但要先確認手工是否支撐正式上架。
   - 飄綠視覺較強，若手工精緻可支撐 HK$980+；若手工一般，建議以 HK$680-980 測款。
   - M010 如果加鍍金，應定價高於 M009 或至少同級。

4. M007 可以做品牌第一對耳線，但不應太平。
   - 成本低，造型有記憶點。
   - 若工藝完整，建議 HK$980-1080，不建議 HK$780 起。

5. M011 可做中性/灰黑測款，但不要當低價款。
   - 若用黑銀/氧化銀效果，成本和售後風險要再問清楚。
   - 建議 HK$980-1180，視完成度再決定。

## 要再確認

- 350 CNY 是否已包含全部銀料、耳勾/耳圈、焊接和基本配件。
- 鍍金 30 CNY 是否每對計，是否已包含清洗和重鍍風險。
- 每對耳環大概用幾多克銀。
- 如果只是現成耳圈/耳勾加小圈連接，權記 M009 實例為 42.2 CNY，但要確認材質、手工、耐用度和售後風險。
- 返工、斷裂、孔位磨損或左右不平衡由誰承擔。
