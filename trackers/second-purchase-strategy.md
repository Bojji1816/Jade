# 第二轉入貨策略

最後更新：2026-08-07
狀態：Draft v0.3

用途：根據第一次四會入貨經驗，調整第二轉入貨方法。核心改變是：不再只看料本身價錢，而是買入前先估「料錢 + 加工 + 銀料/鍍金 + 包裝 + 可售價 + 毛利」。

## 第一轉最大教訓

- 買回來的價格未必知道是否合理，因為第一次未熟市場價。
- 買完回來再查鑲嵌成本，才發現加工比預想高，尤其耳環完整鑲嵌可能要三百幾 CNY 一對。
- 原本以為可做入門價的耳環，計入加工後可能需要賣到 HK$980-1480 才有合理毛利。
- 已鑲嵌好的街貨/成品扣很多偏老土，不符合 COMETA 的現代簡約方向。
- 毛料拋光後才看到部分瑕疵，未拋光前不能按最佳狀態定價。
- 每粒料都要照清楚，不然回來後很難判斷瑕疵、尺寸、形狀和加工空間。

## 第二轉核心策略

第二轉不是買更多，而是買得更準。

第一批入貨後要承認一個現實：當時買回來的價錢未必全部都合理，因為未熟市場價，也未即時計清加工後的總成本。第二轉要用「完成品倒推」去買料，不是用「裸料看起來便宜」去買料。

第二轉總資金暫定 2000-3000 CNY，但不應全部用來買裸料，因為後面仍要留資金做鑲嵌、銀料、鍍金、拋光、打孔和返工。採購目標是盡量用一手價買入，先降低裸料成本，再把資金留給真正能提升產品完成度的加工。

## 第二轉預算框架

| 項目 | 建議預算 | 用途 |
| --- | --- | --- |
| 裸料入貨 | 1200-1800 CNY | 第二批主線明料 / 小件 / 耳飾料 / 小牌 |
| 加工預留 | 800-1200 CNY | 鑲嵌、S925 銀、鍍金、拋光、打孔、返工 |
| 彈性空間 | 0-300 CNY | 只用於非常值得的一手價貨或補配件 |

原則：

- 如果總預算靠近 2000 CNY，裸料最多買約 1200 CNY，至少留 800 CNY 做加工。
- 如果總預算靠近 3000 CNY，裸料最多買約 1800 CNY，至少留 1000-1200 CNY 做加工。
- 任何一件料如果會令加工預留跌穿 800 CNY，要重新判斷是否真的值得買。
- 第二轉要少買高不確定毛料，多買能直接進入設計和加工判斷的明料。

## 一手價採購方向

第二轉要優先找一手價或接近一手價的貨源，目的不是單純買平，而是令完成品成本有空間：

- 優先保留可長期合作檔口：例如天光墟熊哥價錢合理、料是自己做、直接開一口價；B466 亦值得長期跟進。
- 同一類貨先看 3-5 檔，記錄大概價格帶，再決定是否落手。
- 對比同類形狀、大小、種水、顏色、棉裂和孔位，不只比較標價。
- 可小量試買，但不要因為「一手價」而買太多同類貨。
- 一手價貨如果瑕疵、厚薄或加工風險高，仍然不算便宜。
- 成品扣老土的已鑲嵌貨，即使平，都只作學習或拆件可能，不作主線採購。

### 長期合作檔口原則

值得長期合作的檔口不一定是最低價，而是要同時符合幾點：

- 價錢合理，開價穩定，不需要每件大幅議價。
- 料源清楚，例如自己做料或可清楚交代來源。
- 願意處理拋光、補貨、留貨或後續取貨安排。
- 同類貨品質穩定，買回來後 QC 結果和現場判斷接近。
- 溝通直接，能夠支持之後小批量長期採購。

入貨前每件要先估：

```text
預計總成本 = 料錢 + 加工費 + 銀料/鍍金 + 包裝 + 損耗空間
```

再問：

- 這件做完後，合理售價能否落在 HK$500-1500？
- 如果要賣高過 HK$1500，產品質感和設計是否撐得起？
- 如果完整鑲嵌成本高，是否有低加工方案？
- 如果沒有加工方案，是否仍值得買作內容/學習樣本？

### 買前先倒推售價

每件料買入前先用以下方式倒推：

```text
可接受料錢 = 目標售價 - 預計加工/金屬/包裝 - 目標毛利
```

例子：

- 如果一對耳環完成後想賣 HK$980，但鑲嵌和配件已經約三百幾 CNY，裸料就不能太貴。
- 如果裸料本身已經要 180-200 CNY 以上，完整鑲嵌後多數要賣 HK$1080+ 才比較合理。
- 如果產品質感未能支撐 HK$1080+，就應改低加工方案，或不要買作耳環料。

## 第二轉入貨優先次序

| 優先 | 貨種 | 原因 |
| --- | --- | --- |
| 高 | 形狀完整的小吊墜 / 小牌 | 可用 S925 銀扣頭或簡單包邊，成本較容易控制 |
| 高 | 一對成形、孔位乾淨、花色有記憶點的耳飾料 | 可以支撐 HK$980-1480，但買前要先估鑲嵌成本 |
| 中 | 糯冰、淡青、飄綠小件 | 符合 COMETA 日常清爽方向 |
| 中 | 灰黑 / 烏雞小件 | 可測中性和男裝方向，但不要買太多 |
| 低 | 未拋光毛料 | 只在價格足夠低、可承受拋光後出瑕疵時買 |
| 低 | 已鑲嵌成品 | 只有扣頭乾淨現代或可低成本拆件時才考慮 |

## 入貨前成本快算

### 耳環

完整鑲嵌耳環暫用以下粗算：

```text
料錢 + 300-380 CNY 鑲嵌/配件 + 30 CNY 鍍金（如需要） + HK$30 包裝
```

判斷：

- 如果料錢已超過 180-200 CNY，一對耳環做完大多要賣 HK$1080+ 才合理。
- HK$580-780 只適合非常簡單配件或現成 S925 耳圈/耳勾，不適合完整鑲嵌。
- 飄綠、深色花、對稱度好、有設計記憶點，才值得用完整鑲嵌。

### 吊墜 / 小牌

需要先問：

- 只加 S925 銀扣頭是否足夠？
- 是否需要全包邊？
- 玉件邊角是否薄，會否需要底托保護？
- 加工後是否仍能在 HK$680-1280 內有合理毛利？

### 戒面 / 戒指

戒指不是入門低成本款，因為：

- 要處理圈口。
- 鑲嵌結構要求高。
- 售後和尺寸問題較多。
- 加工費容易高過預期。

第二轉可以少量買，但不要大量集中。

## 每粒料必拍照片

入貨現場或買入當日，每粒至少拍：

- 自然光正面。
- 背面。
- 側面厚度。
- 孔位 / 邊角 / 裂位近鏡。
- 尺寸圖或卡尺相。
- 手持比例圖。
- 如是毛料，拋光前後對比。

目的：

- 回來後可判斷加工空間。
- 可用作產品前後對比內容。
- 可追蹤哪些瑕疵是買入時已有，哪些是拋光/加工後出現。
- 可避免之後只憑記憶判斷買得好不好。

照片要求要當成買貨門檻：如果現場不能影清楚，或影完仍看不清裂、孔位、厚薄和邊角，該件應降級為學習款或暫不買。第二轉每粒都要能夠回到家後單靠照片重新判斷一次。

## 第二轉現場決策卡

每件料買前快速寫低：

| 項目 | 要記錄 |
| --- | --- |
| 裸料價 | CNY 價錢和是否議價後 |
| 產品方向 | 吊墜 / 耳環 / 戒指 / 手鏈 / 學習樣本 |
| 加工方法 | 只加扣頭 / 簡單連接 / 完整鑲嵌 / 暫不加工 |
| 加工估算 | 工費、銀料、鍍金、拋光或打孔 |
| 完成品成本 | 料錢 + 加工 + 包裝 + 損耗 |
| 目標售價 | HK$500-800 / HK$800-1200 / HK$1200-1500 / HK$1500+ |
| 風險 | 裂、棉、厚薄、孔位、左右配對、拋光後出瑕疵 |
| 買入原因 | 顏色、形狀、設計感、內容價值或補 SKU 缺口 |

## 下次不要再犯

- 不要買完才第一次估加工成本。
- 不要因為料便宜就忽略鑲嵌後總成本。
- 不要未影清楚就買，尤其是孔位、邊角、裂位和厚度。
- 不要把「買價好像便宜」當成合理，必須用完成品售價和毛利倒推。
- 不要把老土扣頭的已鑲嵌成品當成 COMETA 正式產品。
- 不要用未拋光毛料的最佳想像去定價。
- 不要買回來才發現沒有清晰照片、尺寸或瑕疵記錄。
- 不要把街邊貨混入正式 SKU 成本表。

## 第二轉出發前要準備

- 每類產品的加工成本上限。
- 每件目標售價帶：HK$500-800、HK$800-1200、HK$1200-1500。
- 每類產品最多買幾件，避免某一類買太多。
- 第二轉總資金 2000-3000 CNY；裸料入貨先控制在 1200-1800 CNY。
- 至少預留 800-1200 CNY 做加工，不因現場貨多而用盡。
- 一手價觀察表：同類貨至少比較 3-5 檔後才決定。
- 拍照 checklist。
- 卡尺、白紙/灰卡、小袋、標籤貼、筆。
- 第一轉錯誤清單。

## 待確認

- 第二轉最終使用 2000 CNY、2500 CNY 還是 3000 CNY。
- 女裝日常、男裝烏雞、送禮款比例。
- 是否買毛料，以及毛料預算上限。
- 耳環完整鑲嵌和低加工方案的實際價差。
