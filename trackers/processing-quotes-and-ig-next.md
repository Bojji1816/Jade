# 加工報價 + IG 下一步

最後更新：2026-08-25
狀態：Active checklist

用途：先向工場/師傅確認加工可行性、成本、材質和工期，再決定哪些作品可以進入 IG 預告、Available highlight 和正式上架。

攝影狀態另見：`trackers/launch-photography-status.md`

## 本週順序

1. 先問加工報價：M003、M011、M012、M013。
2. M002 買入時已包原有鑲嵌/扣頭及鏈，先做成品 QC，不列入本輪問價。
3. 同步補已完成件 QC：M002、M004、M009。
4. 報價回來後更新成本、售價和是否值得上架。
5. IG 先做品牌 / Process / Jade 101；等 QC、報價、售價定好後才開 Available。

## 發給師傅的通用開場

```text
你好，我有幾件翡翠想問 925 銀加工報價，首階段想做簡約、日常、不要太傳統的款式。

想請你幫我逐件報：
1. 是否可做這個結構
2. 單件/一對總價
3. 銀重和工費是否分開計
4. 材質是否 925 銀
5. 如做鍍金/黑銀/氧化銀，鍍色另外加幾多錢，會否容易甩色
6. 工期
7. 是否有起訂量
8. 加工時如崩邊、孔位裂、鑲嵌失敗，責任點計
9. 可否完工前影相確認

我會逐件發尺寸、正面、背面、側面和設計參考圖給你。
```

## 報價必問欄位

| 項目 | 要問清楚 |
| --- | --- |
| 材質 | 是否 S925 銀；如不是，要寫明實際底材 |
| 銀重 | 每件/每對預計幾多克，銀料幾多 CNY/克 |
| 工費 | 鑲嵌、焊接、包邊、耳勾、接圈、拋光是否分開計 |
| 鍍色 | 鍍金、黑銀、氧化銀、黑銠、槍黑是否另收；耐磨限制 |
| 結構 | 扣頭、耳勾、包邊、背托、孔位承重是否安全 |
| 工期 | 單件樣板幾耐；多件一齊做幾耐 |
| 起訂 | 單件可否做；起版/CAD 是否另收 |
| 風險 | 崩邊、孔位裂、返工、補鍍、運輸責任 |
| 完工確認 | 可否影正面、背面、側面、接駁位俾我確認 |

## 報價回來後的決策標準

| 結果 | 判斷 |
| --- | --- |
| 立即做 | 工藝安全，單件成本可支撐目標售價，材質可清楚披露 |
| 先重問/改方案 | 工藝可行但成本太高、鍍層不清楚、或風險責任不明 |
| 暫不上架 | 成本令售價超出 HK$500-1500，或安全/耐用風險太大 |
| 只做內容 | 款式有學習價值，但工藝或毛利不適合正式銷售 |

## IG 下一步

報價未回來前：

- 發品牌第一篇 Carousel。
- 發 Process Stories：選料、尺寸、設計圖、問師傅報價。
- 建 `Start Here` Highlight。
- 建 `Process` Highlight。
- 不開 `Available` Highlight。
- 不公開未確認售價。

報價 + QC 完成後：

- 選 3-5 件第一輪 launch SKU。
- 每件補：SKU、尺寸、材質、售價、證書狀態、天然特徵補充披露。
- 發 `Jade, shown honestly` 置頂帖。
- 開 `Available` Highlight。
- Stories 用狀態：Preview / Available / On Hold / Sold。
