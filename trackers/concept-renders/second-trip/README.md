## 建議先問價次序

1. M014：短雙夾片 / 星芒上移直駁吊環。
2. M020：金色小葉扣 open-back。
3. M016 或 M023：金色小葉扣 / 兩點小爪 open-back 單吊咀。
4. M017 / M018：日常平安扣扣頭。
5. M019 / M024 / M025：低工費配珠方案。
6. M022：先問極簡銀扣或黑繩，不急做重工。
