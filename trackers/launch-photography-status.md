# 第一輪定價 SKU 攝影狀態

最後更新：2026-08-26
狀態：Active checklist

用途：只追蹤已定 Launch 價的作品，確認是否已有可上架產品相，以及下一步要補拍甚麼。

## Status Legend

- `未開始`：只有入貨/尺寸相，未有正式產品攝影。
- `部分完成`：已有成品或參考相，但未齊上架所需角度。
- `待配件/QC後拍`：價格已定，但要先確認配件、結構或安全 QC。
- `可安排正式拍攝`：成品方向清楚，可以排入今週拍攝。

1. M012：已有 product-photography v2 flow，可直接照住影真實成品相。
2. M010、M011：已鑲嵌但未有 product-photography flow；先按設計概念圖補攝影方向，然後影完整產品相和配戴相。
3. M002：已有 product-photography flow；若扣頭、鏈和重心 QC 合格，即排主力項鏈攝影。
4. M004：已有 product-photography flow；補安全 QC 細節相，未過安全 QC 前只做禮物/客訂參考內容。
5. M003、M013：配件已定，可補正式上架相；M013 要特別影厚度、扣位承重和上頸重心。

## 每件最少交付相

| 類型 | 必拍 |
| --- | --- |
| 商品照 | 白底正面、背面、側面、45度 |
| 材質披露 | 玉質紋理、棉/石紋/色差、透光、孔位或邊位 |
| 金屬披露 | 925 銀、電鍍黑/鍍色位置、扣頭、接圈、耳勾或鏈 |
| 配戴照 | 上頸/上耳/手持比例，黑衫及白衫各一 |
| 上架素材 | 1張主圖、3-5張詳情圖、1段短片或 Stories clip |
