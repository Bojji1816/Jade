## 使用方法

這個資料夾用來管理可重用品牌文案，包括網站頁面、Instagram highlight、商品頁、包裝卡及客服回覆。

## 文件

- `purchase-notes.md`：翡翠購買須知
- `care-notes.md`：翡翠保養須知
- `product-page-copy.md`：商品頁統一披露文案
- `instagram-launch-kit.md`：Instagram Bio、置頂帖、Highlights 和 DM/WhatsApp 回覆
