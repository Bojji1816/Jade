## 包裝定位

- 產品價格：HK$500-1500。
- 主要客人：Instagram 上 25-35 歲女性。
- 品牌感覺：優雅、現代、細緻、有自家手作品牌的溫度。
- 包裝盒觀感偏好：時尚、設計感；避免過於傳統或厚重的珠寶盒感。
- 包裝方向：高級的環保感，以物料觸感、整齊層次和保護細節建立價值。
- 產品範圍不包括手鐲；手部飾物只需考慮幼鏈手鏈及翡翠珠串／多顆翡翠手鏈。
- 訂單量：每月約 10-50 張。
- 單件包裝預算：HK$30 以內。
- 初期策略：使用現成包裝，不訂製盒；以卡片、貼紙、印章和包裝方式建立品牌感。
- 銷售地區：香港本地及海外。

### 作品身份卡

每件首飾附有一張「作品身份卡」，以 `1/1` 表達每件翡翠首飾均是獨一無二的作品。

核心訊息：

> ONE OF ONE
>
> 1 / 1
>
> 這件首飾，世上只有一件。

卡片可承載：

- 作品名稱或編號。
- 翡翠實物照片。
- 材質。
- 製作日期。
- 製作者簽名或蓋章。
- 保養說明。
- 作品頁面或品牌 Instagram 的 QR code。

稱為「作品身份卡」或「One of One Card」，不稱為鑑定證書。正式寶石鑑定資料另行處理。

### 首飾袋袋型

- 袋型偏好：信封翻蓋式。
- 封口方式：自然覆蓋，不加暗扣、磁石、魔術貼、繩或金屬件。
- 觀感：比抽繩袋更俐落、高級及現代，帶有精品保護套及作品收藏感。
- 用途：優先用作翡翠吊墜的獨立保護袋；頸鏈仍固定在紙卡上，避免打結。
- 未定內容：物料、顏色、尺寸及是否加入品牌標記。

## 按產品類型的包裝組合

整體方向是共用一款 120 x 90 x 40 mm 白色磁吸書型盒，再按產品類型更換固定卡、信封翻蓋袋及保護方式。作品身份卡及保養注意放在盒蓋背，首飾及絨毛袋放在盒身內。

### 項鏈及吊墜組合

建議次序：

1. `1/1` 作品身份卡。
2. 翡翠吊墜放入約 50 x 70 mm 信封翻蓋袋。
3. 頸鏈固定在紙卡上，鏈尾收在卡背或紙套內。
4. 防氧化紙與金屬鏈放在同一層，但不直接貼住翡翠。
5. 放入書型盒右側盒身的紙內托。

重點：吊墜與頸鏈分開，但開箱時要讓客人清楚知道兩者屬於同一件作品。

### 垂墜耳環及 Huggie 耳環組合

首選組合：

1. `1/1` 作品身份卡。
2. 左右耳環固定在約 60 x 65 mm 耳環卡上，保持足夠距離。
3. 耳環卡連產品放入約 70 x 75 mm 信封翻蓋袋。
4. 容易互撞的翡翠之間加入一小片無酸紙作分隔。
5. 整袋放入書型盒右側盒身的紙內托。

適用：M007-M011 的長耳線、Huggie、耳勾及小牌耳墜。

注意：

- 長耳線要沿卡背固定，不能在袋內自由盤繞。
- 翡翠耳墜不能只放入同一個空袋，否則左右會互撞。
- 耳勾、小圈及耳托要有固定孔位，避免運送期間脫落。

### 耳釘組合

1. `1/1` 作品身份卡。
2. 耳釘固定在有厚度或摺疊結構的紙卡上。
3. 耳針背面要預留空間，避免被盒底或首飾袋壓彎。
4. 耳托扣好；如附備用耳托，放入獨立小紙套。
5. 固定卡可放入較深的信封翻蓋袋或直接固定在紙內托。

重點：一般扁平絨布袋不一定適合耳釘，必須先確認耳針不會受壓。

### 幼鏈手鏈組合

1. `1/1` 作品身份卡。
2. 手鏈兩端固定在約 90 x 55 mm 手鏈卡上。
3. 多餘鏈尾收在卡背紙套內。
4. 翡翠或吊飾位置加入小型無酸紙保護套，避免與金屬鏈摩擦。
5. 整張固定卡放入書型盒右側盒身。

可選：如果希望增加柔軟收納感，可將固定卡放入信封翻蓋袋，但要測試疊放厚度。

### 翡翠珠串或多顆翡翠手鏈組合

1. `1/1` 作品身份卡。
2. 手鏈平放入約 85 x 70 mm 信封翻蓋袋。
3. 以薄無酸紙或紙環維持圓形，減少珠粒在運送時集中碰撞。
4. 袋底配合紙內托固定，避免在盒身內移動。

重點：不應拉緊或壓平彈力線；要為珠粒厚度預留足夠盒高。

### 戒指組合

1. `1/1` 作品身份卡。
2. 戒指固定在可拆式紙戒指卡、小紙枕或帶插口的紙內托。
3. 視乎翡翠突出高度，再將固定件放入信封翻蓋袋。
4. 使用內托控制周圍留白，避免細戒指放入大盒後顯得空洞。

## 待比較內包裝：絨布首飾袋

絨布首飾袋可增加柔軟、精緻和可重用的收納感。袋型已偏向信封翻蓋式，但物料及實際規格尚未確認。

### 可選用途

- 只包裹翡翠吊墜，金屬鏈另外固定在紙卡上。
- 翡翠及金屬鏈各用一個獨立小袋，避免碰撞和纏結。
- 作為首飾盒內的可重用收納袋，產品本身仍先以固定卡或保護紙包好。

### 初步建議

- 優先測試信封翻蓋式，比抽繩袋更整齊、高級，亦不會由抽繩位置壓住突出翡翠。
- 封口使用自然覆蓋，不加暗扣、磁石、魔術貼、繩或金屬件，保持簡潔並方便物料分類。
- 吊墜袋可由約 50 x 70 mm 起試，實際尺寸要按完成鑲嵌及扣頭後再確認。
- 頸鏈優先使用固定卡而非單獨放入絨布袋，減少打結風險。
- 耳環及戒指可先固定在產品卡，再決定是否需要額外絨布袋。
- 使用 120 x 90 x 40 mm 磁吸書型盒時，要測試絨布袋及固定卡疊放後會否過厚，並確認盒蓋背的身份卡不會壓住首飾。

### 物料選擇

| 物料 | 觀感 | 優點 | 注意 |
| --- | --- | --- | --- |
| 短毛絨布 | 傳統、柔軟、珠寶感 | 防刮、觸感明顯 | 多為合成纖維，容易黏塵，環保感較弱 |
| 超纖麂皮 | 現代、乾淨、較高級 | 毛短、較少勾鏈，適合細緻首飾 | 通常仍屬合成物料，要查成分及耐用度 |
| 再生聚酯絨布 | 精緻、較符合環保敘事 | 可保留柔軟觸感 | 應要求供應商提供再生成分或 GRS 等資料 |
| 棉布或棉麻 | 自然、手作、環保感較直接 | 容易重用及印章加工 | 纖維較粗，可能勾幼鏈，亦未必有足夠防撞效果 |

### 樣品測試

- [ ] 深色布料用白布摩擦，檢查會否甩色或染色。
- [ ] 檢查毛絨會否黏在鍍金、S925 銀、扣頭或幼鏈上。
- [ ] 幼鏈放置及取出後會否打結或被纖維勾住。
- [ ] 翡翠邊角、鑲爪及扣頭會否勾住袋口。
- [ ] 袋內有否化學氣味、膠水或殘留物。
- [ ] 香港潮濕環境放置數星期後，有否受潮、異味或金屬變色。
- [ ] 重複開關及使用後，袋口是否變形。
- [ ] 確認物料成分、再生比例及是否容易分類回收。

## 第一批貨的首飾盒尺寸建議

根據目前 `M001-M012` 的產品方向及品牌偏好的時尚、設計感，初期使用一款微長方形磁吸書型通用盒：

### 主力尺寸

- 已選尺寸：約 120 x 90 x 40 mm，待供應商確認為外尺寸。
- 建議最低內部可用空間：105 x 75 x 28 mm。
- 購買時必須向供應商確認內尺寸，不能只看外尺寸。
- 作品身份卡可設為標準卡片大小約 85 x 55 mm，放入盒蓋背的簡潔紙卡袋或紙角位。

### 適用產品

| 產品 | 編號 | 包裝方式 |
| --- | --- | --- |
| 項鏈及小吊墜 | M001, M002, M003, M005, M006, M012 | 吊墜放獨立小袋；鏈或繩盤好後分開固定 |
| 長耳線耳環 | M007 | 使用約 70 x 70 mm 耳環卡，耳線沿卡背固定 |
| Huggie、耳勾及小牌耳墜 | M008, M009, M010, M011 | 使用約 60-70 mm 耳環卡，左右分隔固定 |
| 迷你戒指 | M004 | 使用可拆式戒指固定卡或小戒枕，填好周圍空位 |

### 選擇原因

- 第一批產品以小吊墜、項鏈和耳飾為主，120 x 90 mm 微長方形盒能共用同一盒型。
- 微長方形比正方形更有延伸感和現代精品感，較符合品牌偏好的時尚、設計感。
- 最大玉件 M002 約 32.9 x 12.4 x 4.8 mm，加上扣頭及保護空間仍足夠。
- 最厚玉件 M006 約 7.3 mm，加上鑲嵌及內托後，25 mm 內部高度一般足夠。
- 頸鏈與吊墜分開包裝後，不需要使用傳統長形項鏈盒。
- 統一盒型可降低少量採購成本、庫存及包裝複雜度。

### 買盒前測試

- [ ] 用紙或硬卡製作 105 x 75 x 28 mm 的內部空間模型。
- [ ] 測試 M002 的頸鏈固定卡能否放在上層，吊墜絨毛袋能否放在下層，並確保盒蓋背的作品身份卡不會受壓。

## 盒型決定及後備方案

第一階段選擇磁吸書型盒；抽屜款保留為成本或供應後備方案。

### 已選磁吸書型盒

- 盒型：側開式磁吸書型盒。
- 尺寸：120 x 90 x 40 mm。
- 外層：環保白紙成品盒。
- Logo：水晶標貼。
- 內蓋：作品身份卡及保養注意。
- 盒身：首飾、固定卡及信封翻蓋絨毛袋。
- 狀態：方向已確認，待實物樣盒測試。
- 初步判斷：比例符合時尚、設計感，空間足以兼容目前的吊墜、項鏈、耳環和戒指。
- 購買前要確認：120 x 90 x 40 mm 是外尺寸還是內尺寸；盒身內部可用空間建議不少於約 105 x 75 x 28 mm。
- 注意：戒指及細小耳環放入時可能顯得較空，需要合適的固定卡或紙內托控制留白。
- 注意：盒高 40 mm 可能略厚，要連同郵寄盒測試總體積、重量和觀感。

### 磁吸翻蓋款

- 觀感：完整、正式、像精品禮盒，傳統珠寶感相對較強。
- 開箱：打開後一次過看到作品身份卡及首飾排列。
- 優點：盒蓋固定較穩，運送期間不易自行打開；容易重用作收納。
- 注意：磁石令紙盒較難完全分類回收；盒身通常較重及較厚，可能增加成本和運費。
- 設計重點：選薄身、啞面紙質和隱藏磁石，避免厚重或傳統絨面珠寶盒感。

### 抽屜款

- 狀態：後備方案。
- 觀感：時尚、現代、較有設計師品牌及編輯感。
- 開箱：首飾逐步出現，較有揭示感，適合拍攝開箱短片。
- 優點：可使用全紙結構；內部排列清晰，亦方便更換不同產品固定卡。
- 注意：抽屜太鬆會在運送途中滑出，太緊則影響開箱；需要測試紙套摩擦力和耐用度。
- 設計重點：優先使用半圓紙缺口或紙拉手，避免膠製或過長絲帶拉手；外層可用紙腰封或封口貼固定。

### 現階段方向

第一階段選擇白色磁吸書型盒作落樣方向。書型開合可將品牌資料與作品分成清楚的左右兩頁，較能表達每件翡翠是 `1/1` 作品。抽屜款保留作供應、成本或重量不合要求時的後備方案。

### 樣盒比較項目

- [ ] 紙質、盒身厚度及整體重量。
- [ ] 確認供應商標示的是外尺寸或內尺寸。
- [ ] 單手開盒是否順暢。
- [ ] 磁吸力是否足夠固定盒蓋，但不會令開盒太用力。
- [ ] 打開後第一眼能否看到 `1/1` 作品身份卡。
- [ ] 翡翠袋與鏈袋是否有清楚固定位置。
- [ ] 盒內實際可用尺寸。
- [ ] 放入郵寄盒後的總重量及防撞空間。
- [ ] 搖晃、一米跌落及重複開關測試。
- [ ] 物料是否容易分類回收及重用。
- [ ] 水晶標貼在環保白紙表面的黏力、起角、耐刮及撕除後紙面情況。
- [ ] 向供應商確認白紙來源、再生成分或 FSC 等資料；磁石及水晶標貼需另行評估，不直接宣稱整盒可回收。

## 初期暫不採用

- 紙絲。
- 過厚、過重或使用過強磁石的盒。
- 大量絲帶。
- 獨立品牌故事卡。
- 每款產品使用不同專屬盒。

原因：以上項目會增加成本、包裝時間和庫存，但未必明顯提升目前價格帶的體驗。
