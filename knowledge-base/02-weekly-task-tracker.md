# 每週任務追蹤

最後更新：2026-07-14
狀態：Draft v0.3

## 當前焦點

月份：Month 1
主題：第一批 10 件學習貨 + 品牌方向 + 加工打樣

## Week 1：明料盤點

目標：
- 將 10 件四會明料變成可管理的產品資料。
- 初步判斷每件貨適合做什麼。

任務：
- [ ] 為 10 件明料逐件拍照，至少包括正面、背面、側面、近距離瑕疵。
- [ ] 為每件明料建立編號。
- [ ] 記錄尺寸、顏色、種水觀察、裂/棉/瑕疵、厚薄、形狀。
- [ ] 記錄每件明料成本。
- [ ] 初步分類：女裝日常款、男裝烏雞款、吊墜/項鏈、手鏈、耳環/戒指。
- [ ] 寫下每件貨的可加工方向和不適合加工的風險。

完成標準：
- 10 件貨全部有照片、編號、成本和初步加工方向。

## Week 2：加工報價 + Checklist

目標：
- 確認加工可行性和成本。
- 建立第一版入貨和成品檢查標準。

任務：
- [ ] 找加工師傅/鑲嵌師傅查詢報價。
- [ ] 記錄工費、材質選項、工期、起訂要求、損耗風險。
- [ ] 建立入貨 checklist：種水、顏色、裂、厚薄、形狀、加工空間、目標售價。
- [ ] 建立成品 QC checklist：拋光、鑲嵌穩固度、佩戴舒適度、尺寸、瑕疵、照片記錄。
- [ ] 初步判斷哪些貨值得打樣，哪些只適合保留觀察。

完成標準：
- 有加工報價記錄。
- 有入貨 checklist 和成品 QC checklist 第一版。

## Week 3：競品研究 + 品牌方向

目標：
- 補回品牌基本功，不讓產品只停留在「有貨」。
- 決定第一批打樣款。

任務：
- [ ] 做 15-30 個競品研究：香港 IG 店、翡翠珠寶店、現代首飾品牌、男裝烏雞/黑色系飾品。
- [ ] 記錄每個競品的價格、產品類型、照片風格、文案、包裝、客群。
- [ ] 整理 3-5 個品牌名方向。
- [ ] 建立 moodboard：現代簡約、翡翠綠、烏雞黑灰、日常高質感。
- [ ] 決定第一批打樣款式。

完成標準：
- 有競品表初版。
- 有品牌名方向和 moodboard 初版。
- 第一批打樣款式已確認。

## Week 4：落單打樣 + 第二轉入貨準備

目標：
- 將第一批貨推進加工。
- 為第 2 個月第二轉入貨做好準備。

任務：
- [ ] 落單第一批打樣。
- [ ] 建立成本/售價/毛利表。
- [ ] 設定價格層：HK$500-800、HK$800-1200、HK$1200-1500。
- [ ] 整理第一轉入貨經驗：市場路線、檔口、價格區間、質量觀察、議價心得。
- [ ] 寫第二轉入貨目標清單：要找什麼、避免什麼、預算上限、重點主題貨。

完成標準：
- 第一批樣品已落單或部分完成。
- 成本/售價/毛利表可用。
- 第二轉入貨 checklist 和目標清單完成。

## Month 2：第二轉入貨 + 拍攝 + 上架準備

主題：用第一轉學到的經驗買第二批更準的貨，並把第一批樣品變成可銷售內容。

### Month 2 Week 1：第二轉入貨準備

目標：
- 將第一轉入貨經驗變成第二轉入貨行動清單。
- 明確第二轉預算、目標貨種和避免事項。

任務：
- [ ] 覆核第一批 10 件明料記錄，標記最值得繼續買的類型。
- [ ] 整理第一轉入貨錯誤和學到的判斷：裂、厚薄、顏色、形狀、價格、加工空間。
- [ ] 設定第二轉入貨預算上限。
- [ ] 決定第二轉比例：女裝日常款、男裝烏雞款、送禮款。
- [ ] 列出第二轉重點貨種：小吊墜、手串珠、戒面、耳環料、烏雞手鏈料。
- [ ] 更新入貨 checklist。

完成標準：
- 第二轉入貨清單、預算和優先次序已確認。

### Month 2 Week 2：第二轉入貨執行

目標：
- 完成第二轉入貨，並即時記錄所有重要資料。

任務：
- [ ] 按 checklist 進行第二轉入貨。
- [ ] 逐件記錄成本、尺寸、顏色、瑕疵、可加工方向和目標售價。
- [ ] 拍攝入貨當日照片和每件明料細節。
- [ ] 記錄檔口、價格區間、議價空間和市場觀察。
- [ ] 初步標記哪些貨會加工、哪些貨保留、哪些貨需要再評估。

完成標準：
- 第二批貨已購入並完成基礎記錄。

### Month 2 Week 3：第一批樣品檢查 + 拍攝準備

目標：
- 將第一批樣品從「加工完成」推進到「可以拍攝和定價」。

任務：
- [ ] 檢查第一批樣品：拋光、鑲嵌、尺寸、佩戴舒適度、瑕疵。
- [ ] 用成品 QC checklist 決定每件是否可上架。
- [ ] 完成產品命名和初步 SKU 編號。
- [ ] 更新成本/售價/毛利表。
- [ ] 準備拍攝清單：白底圖、細節圖、上身圖、男女佩戴圖。
- [ ] 準備產品文案框架：尺寸、材質、寓意、保養、適合場合。

完成標準：
- 第一批產品已分為可上架、需修改、暫不上架三類。
- 拍攝清單和文案框架已完成。

### Month 2 Week 4：品牌基礎 + 上架準備

目標：
- 完成第一版品牌和銷售基礎，準備 Month 3 小批量上市。

任務：
- [ ] 確認 working brand name。
- [ ] 更新 moodboard，定下照片、包裝、顏色和字體方向。
- [ ] 建立 IG/網站基礎頁面。
- [ ] 建立 FAQ 初版：天然翡翠/A貨、證書、保養、運送、退換、尺寸、送禮。
- [ ] 確認香港交收/寄送、海外寄送初步政策、退換和瑕疵處理原則。
- [ ] 確認包裝方案：首飾盒/袋、保養卡、感謝卡。
- [ ] 完成第一批產品拍攝或排期。

完成標準：
- 品牌名、FAQ、售後政策、包裝方向和上架基礎已完成。

## Month 3：第一輪小批量上市測試

主題：小量上架第一批成品，開始收集真實市場反應。

### Month 3 Week 1：第一批產品上架

目標：
- 完成第一批產品小量上架。

任務：
- [ ] 選出第一批上架 SKU。
- [ ] 完成每件產品照片、售價、尺寸、材質、保養和故事文案。
- [ ] 在 IG/網站/私域發布第一批產品。
- [ ] 建立查詢紀錄表：客人問題、來源、感興趣 SKU、價格反應。
- [ ] 建立每週 dashboard：查詢數、成交數、銷售額、毛利、庫存、最高反應 SKU。

完成標準：
- 第一批產品已公開展示並可接受查詢/下單。

### Month 3 Week 2：內容測試 + 客人問題收集

目標：
- 測試不同內容方向，了解客人最關心什麼。

任務：
- [ ] 發布四會選料故事內容。
- [ ] 發布加工前後對比內容。
- [ ] 發布女性日常穿搭內容。
- [ ] 發布男裝烏雞低調商務內容。
- [ ] 發布送男朋友/伴侶的禮物內容。
- [ ] 整理客人常問問題，更新 FAQ。

完成標準：
- 至少測試 5 類內容方向，並記錄互動和查詢反應。

### Month 3 Week 3：第二批加工安排

目標：
- 根據第二批貨特性和早期市場信號，安排第二批加工。

任務：
- [ ] 從第二批貨中選出加工款。
- [ ] 決定每件貨加工方式：鑲嵌、手串、吊墜、戒指、耳環。
- [ ] 向加工師傅確認報價、工期和風險。
- [ ] 更新成本/售價/毛利表。
- [ ] 標記哪些款是女裝日常、男裝烏雞、送禮款。

完成標準：
- 第二批加工清單和成本估算已確認。

### Month 3 Week 4：第一輪市場反應回顧

目標：
- 判斷第一批哪些信號值得追，哪些要停止。

任務：
- [ ] 整理查詢數、成交數、收藏/留言、價格反應和客人問題。
- [ ] 標記高反應 SKU、低反應 SKU、需要重拍/重寫文案 SKU。
- [ ] 更新 dashboard。
- [ ] 更新 FAQ、產品頁和銷售話術。
- [ ] 初步判斷 Month 4 第二批 drop 的主打方向。

完成標準：
- 有第一份市場反應回顧和 Month 4 優化清單。

## Month 4：第二批 Drop + 內容和銷售優化

主題：用第一批反應推出更準的第二批產品，並改善銷售內容。

### Month 4 Week 1：第二批成品 QC + 拍攝

目標：
- 第二批成品完成檢查和拍攝。

任務：
- [ ] 用成品 QC checklist 檢查第二批產品。
- [ ] 更新每件產品成本、售價和毛利。
- [ ] 拍攝白底圖、細節圖、上身圖和男裝佩戴圖。
- [ ] 決定第二批主打產品和輔助產品。

完成標準：
- 第二批產品可準備上架。

### Month 4 Week 2：第二批 Drop 上架

目標：
- 第二批產品正式小量上架。

任務：
- [ ] 完成第二批產品頁和 IG 內容。
- [ ] 加強男裝烏雞內容：低調商務、情侶送禮、日常佩戴。
- [ ] 發布第二批 drop 內容。
- [ ] 記錄第二批每個 SKU 的查詢、成交、客人問題。

完成標準：
- 第二批產品已上架，並開始有市場反應紀錄。

### Month 4 Week 3：FAQ / 售後 / 話術優化

目標：
- 將客人問題變成更清楚的信任內容。

任務：
- [ ] 更新 FAQ：天然翡翠/A貨、證書、保養、尺寸、運送、退換。
- [ ] 更新售後政策：瑕疵處理、退換條件、海外寄送限制。
- [ ] 寫 5-10 條常用銷售回覆。
- [ ] 優化產品頁文案和照片排序。
- [ ] 整理最常阻礙成交的 3 個問題。

完成標準：
- FAQ、售後政策和銷售話術有可用版本。

### Month 4 Week 4：合作名單 + 第三轉判斷

目標：
- 開始測試外部流量，並判斷是否需要第三轉入貨。

任務：
- [ ] 建立 5-10 個微型合作對象名單：朋友推薦、micro-influencer、stylist、popup、寄售店。
- [ ] 決定合作形式：佣金、贈品、折扣碼、借貨拍攝或固定費。
- [ ] 整理 Month 3-4 dashboard。
- [ ] 決定第三轉入貨、補貨或暫緩。
- [ ] 寫第三轉入貨/補貨清單。

完成標準：
- 有合作/KOL 名單。
- 有第三轉入貨或補貨決定。

## Month 5：補貨/第三轉入貨 + 渠道測試

主題：根據數據補貨，開始測試更清晰的銷售渠道。

### Month 5 Week 1：補貨或第三轉入貨

目標：
- 按數據和 checklist 入貨，而不是純靠感覺。

任務：
- [ ] 根據 Month 3-4 數據決定入貨重點。
- [ ] 按入貨 checklist 進行第三轉入貨或補貨。
- [ ] 優先考慮表現較好的方向：女裝日常款、男裝烏雞手鏈、送禮款。
- [ ] 更新入貨紀錄、成本表和庫存表。

完成標準：
- 第三轉入貨/補貨已完成或明確決定暫緩。

### Month 5 Week 2：渠道測試

目標：
- 小規模測試不同銷售渠道。

任務：
- [ ] 測試朋友推薦或 referral。
- [ ] 聯絡微型 KOL 或 stylist。
- [ ] 評估 popup 或寄售店機會。
- [ ] 如預算允許，測試小額廣告。
- [ ] 為每個渠道記錄成本、查詢、成交和客人質量。

完成標準：
- 至少測試 1-2 個新渠道，並有初步數據。

### Month 5 Week 3：系列概念整理

目標：
- 把零散產品整理成更容易理解的系列。

任務：
- [ ] 整理可延續系列，例如「日常翡翠」、「烏雞男裝」、「送禮款」。
- [ ] 為每個系列寫一句定位。
- [ ] 更新 IG highlight/網站分類。
- [ ] 改善包裝、拍攝、定價和銷售話術。

完成標準：
- 產品不再只是單件上架，而是有初步系列概念。

### Month 5 Week 4：月度 Dashboard 回顧

目標：
- 用數據決定下一步擴什麼。

任務：
- [ ] 整理銷售額、毛利、庫存金額、查詢數、成交率、熱賣 SKU。
- [ ] 標記最值得補貨的款式。
- [ ] 標記最不值得繼續做的款式。
- [ ] 更新入貨 checklist 和產品設計方向。
- [ ] 初步寫 Month 6 穩定營運清單。

完成標準：
- 有 Month 5 dashboard 和清晰的 Month 6 優先事項。

## Month 6：穩定營運 + 下一季計劃

主題：把前 5 個月測試整理成可重複營運流程。

### Month 6 Week 1：營運資料整理

目標：
- 將所有入貨、加工、銷售和庫存資料整理成可管理資料。

任務：
- [ ] 整理完整成本、毛利、銷售、庫存和入貨紀錄。
- [ ] 對齊每件 SKU 的成本、售價、狀態和照片。
- [ ] 整理加工師傅表現：工期、品質、溝通、返工情況。
- [ ] 整理最常見客戶問題和售後問題。

完成標準：
- 所有核心營運資料已整理到可持續更新的狀態。

### Month 6 Week 2：流程標準化

目標：
- 建立可重複流程，減少每次都重新想。

任務：
- [ ] 完善入貨 checklist。
- [ ] 完善成品 QC checklist。
- [ ] 完善 FAQ 和售後政策。
- [ ] 寫入貨到上架流程：入貨、記錄、加工、QC、拍攝、定價、上架、售後。
- [ ] 確認長期加工合作方式。

完成標準：
- 有可重複的入貨、加工、QC、拍攝、上架、銷售、補貨流程。

### Month 6 Week 3：下一季產品和入貨計劃

目標：
- 決定下一個 3 個月集中做什麼。

任務：

- [ ] 決定下一季是否加強女裝、男裝烏雞、送禮款或新系列。

- [ ] 決定網站是否升級、是否正式投廣告、是否做 popup/寄售。

完成標準：
- 下一個 3 個月產品和入貨方向清楚。

- 下一季 3 個月增長計劃完成。

## 後續固定節奏

- 每週：更新任務進度、客人問題、加工狀態、內容發布。
- 每月：更新 dashboard，包括銷售額、毛利、庫存金額、查詢數、成交率、熱賣 SKU。
- 每次入貨後：更新入貨 checklist 和入貨復盤。
- 每次上架後：更新產品反應、FAQ、售後問題和補貨判斷。
