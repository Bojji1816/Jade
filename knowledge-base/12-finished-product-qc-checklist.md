# 成品 QC Checklist

最後更新：2026-08-17
狀態：Draft v0.1

用途：每件翡翠由明料變成成品後，用這份 checklist 判斷是否可以上架、需要修改，還是只作學習樣本。尤其適用於 M004 小腳繩、M009 權記低加工耳環，以及之後所有鑲嵌、編繩、扣頭和耳飾成品。

## QC 結果分類

| 結果 | 定義 | 下一步 |
| --- | --- | --- |
| 可上架 | 結構穩固、佩戴舒適、瑕疵已記錄、照片可清楚披露 | 補產品資料、定價、拍攝、上架 |
| 需修改 | 玉件本身可用，但配件、工藝、尺寸或佩戴感需要修正 | 回工場/師傅修改，再重新 QC |
| 學習樣本 | 工藝或狀態不足以代表 COMETA 正式品質 | 只作內部記錄、內容對比或成本學習 |
| 不上架 | 有安全、穩固或重大瑕疵風險 | 不售賣；保留紀錄避免重犯 |

## 通用成品 QC

每件成品檢查：

- [ ] 玉件正面沒有新增崩邊、裂紋或明顯刮花。
- [ ] 玉件背面和側邊沒有加工造成的新傷。
- [ ] 孔位、邊角和薄位沒有被金屬或繩結磨損。
- [ ] 拋光狀態乾淨，沒有明顯膠水、蠟、污漬或指紋殘留。
- [ ] 金屬配件、扣頭、耳勾、耳圈或繩結穩固，輕拉不鬆。
- [ ] 左右配對合理，耳環高度、方向、顏色和厚度不突兀。
- [ ] 配戴時不刮皮膚、不勾衣物、不過重、不容易反轉。
- [ ] 成品比例符合 COMETA 現代簡約方向，不顯老土或過度裝飾。
- [ ] 已記錄實際成品成本：裸料 + 加工 + 配件 + 包裝。
- [ ] 已拍攝 QC 照片：正面、背面、側面、接駁位、瑕疵位、上身/上耳。
- [ ] 已決定產品披露：天然翡翠/危料、是否有證書、配件材質、鍍金與否。
- [ ] 已決定售價帶，且毛利合理。

## 耳環 QC

適用：M007、M008、M009、M010、M011、M016、M023、M026-M028。

- [ ] 兩邊高度一致，肉眼不會一高一低。
- [ ] 耳勾、耳圈或耳針材質已確認。
- [ ] 接圈開口已壓實，沒有尖位刮手。
- [ ] 玉件垂墜方向自然，不會長期反面。
- [ ] 孔位承重合理，輕搖不會卡住或磨邊。
- [ ] 上耳後重量可接受，不拉耳洞。
- [ ] 如果是鍍金或氧化銀，已評估褪色和保養說明。

## 吊墜 / 項鏈 QC

適用：M001-M003、M005-M006、M012-M015、M017-M022、M024-M025。

- [ ] 扣頭、吊環或包邊承重穩固。
- [ ] 吊墜重心自然，上頸不會嚴重側翻。
- [ ] 鏈長和吊墜大小比例合理。
- [ ] 扣頭不遮住玉件最重要紋理。
- [ ] 包邊如有壓邊，金屬有實際固定玉件，不只是外框。
- [ ] 鏈和玉件分開收納時不會互相刮花。

## 手繩 / 腳繩 QC

適用：M004 及未來客訂禮物款。

- [ ] 繩結穩固，輕拉不鬆。
- [ ] 調節位順滑，不會太易滑開。
- [ ] 尾繩長度安全，不會過長纏繞。
- [ ] 玉件孔位沒有被繩磨出白痕、崩口或裂紋。
- [ ] 尺寸適合目標佩戴者；如是 BB/小朋友款，必須成人監護下佩戴。
- [ ] 對客文案不宣稱小朋友可長時間或無監護佩戴。

## 上架前最後確認

- [ ] 已完成白底圖、細節圖、佩戴圖。
- [ ] 已寫好尺寸、材質、天然特徵和保養說明。
- [ ] 已披露明顯棉、裂、色差、工藝限制或手作痕跡。
- [ ] 已決定是否附證書；如沒有證書，不用暗示已鑑定。
- [ ] 已確認包裝能保護該類成品，不會壓到玉件、耳勾、扣頭或繩結。
- [ ] 已記錄最終狀態於 `trackers/material-inventory.md`。
