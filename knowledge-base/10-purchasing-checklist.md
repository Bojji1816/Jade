# 入貨 Checklist

最後更新：2026-08-07
狀態：Draft v0.5

用途：每次入手明料、裸石或半成品前，用這份 checklist 快速判斷「值不值得買、買完可以做什麼、成本是否合理」。第一版先保持簡單，之後每次入貨復盤再加上新的經驗。

## 使用原則

入貨前不要只問「靚唔靚」或「平唔平」。每件料至少要先回答幾個核心問題：

- 它買回來想做什麼產品？
- 加工後是否仍能落在 AFTERGLOW 的價格帶和風格？
- 料錢加加工、包裝和損耗後，是否仍有合理毛利？
- 它的買入價是否有市場比較，而不是只靠第一眼感覺？
- 這件是否接近一手價，還是已經被中間層加價？
- 這個檔口是否值得長期合作，例如價錢合理、料源清楚、開價直接和後續安排穩定？
- 買入原因是否清楚，不只是因為一時喜歡或覺得便宜？

## 入貨 Checklist v0.1

每件料入手前先過以下問題：

- [ ] 有明確產品方向：吊墜 / 耳環 / 戒指 / 手鏈 / 男裝 / 送禮
- [ ] 形狀適合加工，不需要大幅改形
- [ ] 厚度足夠，不容易加工時爆邊
- [ ] 無明顯大裂；如有裂，已判斷位置和風險
- [ ] 棉、飄花、雜色可以接受，或可變成產品特色
- [ ] 顏色及天然個性符合 AFTERGLOW：淡青、糯冰、灰黑、飄綠、薰衣草、蜜黃或其他有清楚設計理由的色澤
- [ ] 成本加加工後仍能落在 HK$500-1500 價格帶
- [ ] 已粗算完整成本：料錢 + 加工費 + 銀料/鍍金 + 包裝 + 損耗空間
- [ ] 已用完成品售價倒推，確認裸料價仍有毛利空間
- [ ] 已比較同類貨 3-5 檔，確認價格不是只靠感覺判斷
- [ ] 已記錄檔口是否值得長期合作：價錢、料源、開價方式、拋光/留貨/取貨安排
- [ ] 買入後仍有足夠加工預算，不會因為買料用盡資金
- [ ] 已估算適合用 S925 銀 / S925 銀鍍金 / 暫不加工
- [ ] 如是毛料，已接受拋光後才可能見到棉、裂、髒點或邊角瑕疵
- [ ] 如是已鑲嵌成品，扣頭和配件風格符合 AFTERGLOW，或可低成本拆件重做
- [ ] 有拍照記錄：自然光、背面、側面、近鏡瑕疵、尺寸
- [ ] 每粒已拍清楚：正面、背面、側面、孔位/邊角/裂位近鏡、手持比例
- [ ] 回看照片時仍能清楚判斷裂、厚薄、孔位和加工空間
- [ ] 買入原因清楚，不只是因為便宜或一時喜歡

## 快速判斷

| 結果 | 判斷 |
| --- | --- |
| 15-18 項通過 | 可以考慮買入，買後即時記錄成本、照片和加工方向 |
| 10-14 項通過 | 只適合低價學習或內容款，買之前要清楚知道風險 |
| 少於 10 項通過 | 暫不買，除非有非常明確的學習目的 |

## 一定要停一停的情況

- 只因為便宜而想買，但未想到產品方向。
- 未估加工成本，只知道料錢好像便宜。
- 沒有用完成品售價倒推，未知道買入價是否真的合理。
- 為了追求一手價而買太多同類貨，令加工預算不足。
- 只聽賣家說是一手價，但未比較同類貨價格和質量。
- 現場照片拍不清楚，回來後無法判斷裂、厚薄、孔位和邊角。
- 明顯有裂，但未能判斷裂是否影響加工。
- 形狀需要大幅改形，會增加工費和損耗風險。
- 毛料未拋光，但價格已經接近成品料，風險不對稱。
- 已鑲嵌成品扣頭老土、厚重或比例不靚，但又不能低成本拆件重做。
- 加工後售價要高於 HK$1500 才有合理毛利，但產品質感未必撐得起。
- 顏色、形狀或風格太傳統，與 AFTERGLOW 的現代日常及「依玉而設計」方向不一致。
- 賣點只剩「天然翡翠」四個字，沒有佩戴場景或設計方向。

## 入貨後即時記錄

每次買入後，當日最好補齊：

- 編號。
- 入貨日期。
- 成本和幣種。
- 尺寸、厚度、重量或珠徑。
- 自然光照片、背面、側面、近鏡瑕疵、尺寸圖。
- 顏色、種水、棉、裂、雜色、孔位或邊角狀態。
- 初步產品方向和加工風險。
- 預計售價帶和是否值得加工。

## 復盤規則

每次入貨後回看：

- 哪件買得好？為什麼？
- 哪件買錯？下次要避免什麼？
- 哪些顏色、形狀、厚度最容易變成可售產品？
- 哪些料看起來便宜，但加工後反而成本太高？
- 哪些料買回來後才發現價格不合理？
- 哪些檔口值得長期合作？原因是價錢合理、自己做料、開價直接，還是後續安排穩定？
- 哪些毛料拋光後出現了原本看不到的瑕疵？
- 哪些已鑲嵌成品因扣頭或配件風格不合，反而不適合做 AFTERGLOW？
- 哪些款能支撐 AFTERGLOW 的現代、日常、天然個性及依玉而設計方向？

每次買錯一件，就在 checklist 加一條「下次不要再犯」。
